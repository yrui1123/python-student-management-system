# StudentCMS python-student-management-system 学生管理系统

## 项目简介
来自黑马程序员Python公开课，面向对象单元的项目作业   
原作业使用纯文本存储学生信息,学习后使用pandas改为用excel存储

## 主要功能
- add student information
- delete student information
- update student information
- search single student information
- print all students information
- save students information
- quilt CMS
